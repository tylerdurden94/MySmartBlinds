The bridge-page examples are labeled on the images. They use sample Wi-Fi and
blind records, not a live bridge or anyone's private backup. Never copy their
sample addresses or names as your own configuration.

The Android images are real app captures, not mockups. Their values illustrate
one customized installation and **are not the shipped defaults or recommended
starting values**. In particular, the displayed retry limit of 15 is the maximum,
not a beginner recommendation. Start with 0 for reliable motors, or try 1–3 for
an intermittent motor while observing it. The pictured polling setting is Off;
the shipped default is 2 minutes.

The shown temperature conversion is Provisional. Neither plausible temperatures
nor the light bar establish accurate temperature/lux calibration. Leave temperature
conversion disabled and lux calibration at 0 unless independently validated. The
guides' settings tables describe defaults and limitations.

No bridge token, Wi-Fi password, motor pairing key, or private backup is included.
